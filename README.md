# Choi, EunJung — 개인 소개 페이지

금융감독원에서 근무하며 DFMBA 8기 과정을 함께 듣고 있는 최은정의 개인 소개 페이지입니다.
클라우드컴퓨팅실습 개인 과제로, 화면을 보여주는 프론트엔드와 요청에 응답하는 백엔드가 실제로 어떻게 연결되는지 직접 구현하며 저를 소개하는 방식으로 구성했습니다.

## 구성

| 계층 | 역할 | 배포 |
|---|---|---|
| 프론트엔드 | 소개 화면 (HTML/CSS/JS) | Vercel |
| 백엔드 | REST API (FastAPI) | Render |

## 배포 주소

- Vercel (개인 소개 페이지): https://my-intro-one-chi.vercel.app
- Swagger UI (API 문서·테스트): https://my-intro-6i2d.onrender.com/docs

## 프론트엔드·백엔드 연동

- **날씨 위젯**: 페이지를 열면 프론트엔드가 백엔드 `/weather`를 자동으로 호출합니다. 백엔드는 외부 날씨 API(Open-Meteo)를 호출해 실시간 날씨를 가져오며, 실패 시 재시도 후에도 안 되면 오류 없이 "정보 없음"으로 안전하게 처리합니다.
- **오늘의 추천**: "나의 백엔드" 영역의 🎲 버튼을 누르면 백엔드 `/pick`을 호출해, 즐겨보는 콘텐츠 중 하나를 무작위로 추천받고 그 영상이 페이지 안에서 바로 재생됩니다. 외부 API 없이 서버 자체 로직으로 동작해 안정적으로 작동합니다.

CORS는 Render 환경변수 `ALLOWED_ORIGINS`로 Vercel 배포 주소만 허용하도록 설정했습니다.

## 주요 API

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/weather` | 외부 날씨 API(Open-Meteo) 연동, 페이지 로드 시 자동 호출 |
| GET | `/pick` | 즐겨보는 콘텐츠 중 하나를 서버가 무작위로 추천 |

## 추가 구현 (현재 화면에서는 미사용)

개발 과정에서 함께 구현했으나 최종 화면 구성에서는 제외한 엔드포인트입니다. Swagger UI에서 확인·테스트 가능합니다.

- `GET /hobbies`, `GET /routine` — 취미·루틴 반환
- `GET`, `POST /guestbook` — 방명록 등록·조회 (DB 연동 실습용). Supabase 없이도 SQLite로 동작은 하지만, Render 무료 플랜 특성상 재배포·슬립 시 데이터가 초기화되어 진짜 영속화를 보여주기 어려워 화면에서는 제외했습니다.
